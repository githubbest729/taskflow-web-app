Process Topology & Mimic

Alarm Summary (ISA-18.2 style)

    Quick Guide

    Overview & Mimic

    The Mimic shows the process train: Tank T-101 → XV-101 → pumps P-A/B → MOV-301 → pipeline → CDU-01. Every node has a symbol and a status word (● normal, ◆ advisory, ▲ critical, ○ off) — colour is never the only cue (ISA-101).

    1. Watch the header banner and the UNACK counter.
    2. Press ACK in the Alarm Summary (or click the banner): flashing red becomes solid muted red (ISA-18.2).
    3. Use Demo Scenarios to practise and Reset to Normal to start clean.

    Tank Farm

    Each card shows level against API 2350 setpoints (HH 95 / H 90 / L 10 / LL 5 %).

    1. Press FILL / HOLD / DRAIN to move a tank. ESD closes XV-101 (stops fill) and XV-102 (stops drain).
    2. In the NSV calculator enter observed level, temperature, density @ 15 °C and free-water level.
    3. Read the breakdown: TOV → GOV (TOV − FW) → VCF → NSV. Indicative only; verify with certified tables.

    ESD Cause & Effect

    Rows are initiators (I1–I6), columns are actions (A1–A6). Hover a header for the full tag name.

    1. Trip simulates an initiator: its row turns amber, tripped action columns turn red, and the first initiator gets a ① FIRST-OUT badge.
    2. Bypass inhibits an initiator after a confirmation — it is a logged reduction in SIL-3 protection.
    3. Clear or bypass every active initiator, then press Reset ESD latch. If blocked, the culprit flashes.

    LPG & Pipeline

    1. LPG: Start/Stop a skid, move the VFD speed slider (30–50 Hz), and use Swap duty. Pick a fault to see trips (vibration > 7.1 mm/s, suction < 1.0 barg) and standby auto-start.
    2. Interlock override inhibits trips after confirmation — use with care.
    3. Pipeline (API 1130): press Simulate leak, choose the KM; CPM alarms when flow imbalance exceeds 1.5 %. Close sectional valves SV-1/SV-2 to isolate.

    Loop Calibrator

    1. Set LRV, URV, unit and tolerance (default ±0.1 % span).
    2. Select a test point (0 / 25 / 50 / 75 / 100 % = 4 / 8 / 12 / 16 / 20 mA), source it from your calibrator and enter the Measured mA.
    3. Read the deviation and PASS/FAIL tag, press Record point, repeat for all five points.
    4. Add punchlist items (saved locally) and press Export report (CSV).
